## 🌟 Executive Overview

**GS-III MASTER** consolidates the vast and dynamic General Studies Paper III syllabus into an interconnected, multi-layered digital textbook, live indicator dashboard, concept visualizer, MCQ practice simulator, and Mains answer-writing lab.

Designed with an **"Official-Source-First"** architecture, all economic data, agricultural metrics, scientific developments, and disaster protocols are grounded in primary sources:
* **Economic Data**: Ministry of Statistics and Programme Implementation (MoSPI), Reserve Bank of India (RBI), Union Budget, and Economic Survey.
* **Agriculture**: Commission for Agricultural Costs and Prices (CACP), Ministry of Agriculture & Farmers Welfare, NITI Aayog.
* **Science & Tech**: Department of Science and Technology (DST), ISRO, MeitY, Indian Semiconductor Mission.
* **Environment**: Ministry of Environment, Forest and Climate Change (MoEFCC), Wildlife Institute of India (WII), IPCC AR6, IUCN Red List.
* **Disaster Management**: National Disaster Management Authority (NDMA), India Meteorological Department (IMD), Sendai Framework.
* **Internal Security**: Ministry of Home Affairs (MHA), NCIIPC, CERT-In, Financial Action Task Force (FATF).

## 🏛️ Comprehensive Module Architecture

### 1. 📊 Executive Dashboard
* **Syllabus Progress Tracker**: Live tracking of completed syllabus themes with visual completion bars.
* **Countdown Clocks**: Dual real-time countdown timers for both **UPSC CSE Prelims** and **UPPSC PCS Prelims**.
* **Live Economic Indicators**: Real-time ticker cards covering Real GDP Growth, CPI Inflation, WPI, Fiscal Deficit target, Forex Reserves, Capex outlay, and Unemployment Rate (PLFS).
* **Adaptive Practice Recommender**: Intelligent study prompts based on historical performance in the Prelims and Mains engines.
* **Dynamic Daily Study Planner**: Interactive time-budget scheduler supporting 30-minute, 1-hour, 2-hour, and 4-hour high-yield study blocks with curated topic handoffs.

### 2. 🔬 Signature 18-Dimension Issue Analyser
An analytical workspace dissecting complex GS-III issues across 18 distinct parameters:
1. Core Problem & Constitutional/Statutory Basis
2. Historical Context & Structural Evolution
3. Quantitative Indicators & Data Bank
4. Stakeholder Matrix (Winners vs Losers)
5. Government Interventions & Schemes
6. Institutional Architecture & Committees
7. Bottlenecks & Critical Friction Points
8. Global Benchmarks & Comparative Models
9. Forward Strategy & NITI Aayog Recommendations
10. Prelims Memory Hooks & Elimination Traps
11. Mains 10-Marker Model Framework
12. Mains 15-Marker Model Framework
13. Schematic Diagram / Flowchart Pointers
14. Ethical / Human Development Dimensions
15. State-Level Disparities & Regional Case Studies
16. Inter-linkages with GS-I, GS-II & GS-IV
17. Current Affairs Anchor & Recent Triggers
18. High-Yield Revision Summary (3-Line Formula)

*Includes canonical pre-loaded dossiers (e.g., *Groundwater Depletion & Agri-Power Nexus*, *AI Governance & Sovereign Compute*, *Climate Vulnerability & Net-Zero 2070*) plus an **Interactive Custom Issue Builder**.*

### 3. 📈 Indian Economy & Macro-Development
* **Conceptual Explainers**: Step-by-step interactive breakdowns of GDP vs GVA, Monetary Policy Framework & MPC, FRBM Act trajectory, Balance of Payments (BoP), and the Lewis Model of Structural Transformation.
* **Macro Dashboard**: Visual indicators tracking fiscal, monetary, and external sector health.
* **Union Budget Explorer**: Expenditure vs Receipts composition, Capital vs Revenue outlays, and key flagship scheme allocations.
* **Economic Survey Hub**: Core thematic chapters and structural reform insights.
* **Planning History (1951–Present)**: Interactive chronological roadmap from the Harrod-Domar 1st Plan through the LPG 1991 reforms to NITI Aayog's Action Agendas.

### 4. 🌾 Agriculture & Food Processing
* **Crop Master Database**: Kharif, Rabi, and Zaid classifications with exact temperature, rainfall, soil requirements, and leading producer states.
* **State Cropping Profiles**: Deep-dive comparisons across Uttar Pradesh, Punjab, Maharashtra, and Madhya Pradesh.
* **Irrigation Technology Matrix**: Comparative metrics on Drip, Sprinkler, Canal, and Tubewell systems covering water efficiency, capital costs, and subsidy schemes (PMKSY).
* **Verified MSP Reference**: Real CACP MSP data calculated on the A2+FL formula across cereals, pulses, and oilseeds.
* **PDS Supply Chain**: Visual flowchart detailing FCI procurement, central pool allocation, Fair Price Shop distribution, and ONORC porting.
* **Food Processing Farm-to-Fork Flow**: 6-tier supply chain from post-harvest management and cold chains to PMKSY Mega Food Parks.

### 5. 🚀 Science, Technology & Innovation
* **Core Technology Pillars**: Deep dives into Artificial Intelligence & DPI (India Stack), Biotechnology (CRISPR-Cas9 & CAR-T therapy), Quantum Computing (National Quantum Mission), and Semiconductor Manufacturing (India Semiconductor Mission).
* **ISRO Space Timeline**: Interactive chronological catalog of landmark missions (Chandrayaan-3, Aditya-L1, XPoSat, Gaganyaan, NISAR, Shukrayaan).
* **IPR & Patent Regime**: India's patent framework, Section 3(d) of the Patents Act against evergreening, Compulsory Licensing, and TRIPS flexibilities.

### 6. 🌿 Environment, Biodiversity & Climate Change
* **Species Red List Matrix**: High-yield wildlife profiles (Great Indian Bustard, Bengal Tiger, Gangetic Dolphin, Snow Leopard, Olive Ridley Turtle) with IUCN status, Wildlife Protection Act (WPA 2022 Amendment) schedules, CITES appendices, key threats, and conservation sanctuaries.
* **Global Conventions**: Analytical breakdowns of UNFCCC (Paris Agreement Article 6 carbon markets), CBD (Kunming-Montreal 30x30 target), and Ramsar Wetland conservation.
* **EIA 2006/2020 Flowchart**: 6-stage lifecycle walkthrough covering Screening, Scoping, Public Consultation, Appraisal, Environmental Clearance, and Post-Clearance Monitoring.

### 7. 🌊 Disaster Management
* **Multi-Hazard Vulnerability**: Interactive explorer for Seismic Zonation (Zones II–V), Tropical Cyclone warning categories & IMD color codes (Yellow, Orange, Red), Urban Flooding dynamics, and Glacial Lake Outburst Floods (GLOFs).
* **4-Stage Disaster Cycle**: Prevention & Mitigation, Preparedness, Response & Relief, Recovery & Reconstruction.
* **3-Tier Institutional Architecture**: NDMA (PM-headed), SDMA (CM-headed), DDMA (DM-headed), and the National Disaster Response Force (NDRF).
* **Gold-Standard Case Studies**: Odisha's Mission Zero Casualty and the South Lhonak Glacial Lake Outburst Flood (Sikkim 2023).

### 8. 🛡️ Internal Security & Cyber Defense
* **Threat Matrix**: In-depth strategy dossiers on Left-Wing Extremism (SAMADHAN doctrine & Bastar red corridor), North-East Insurgency, and J&K Hybrid Warfare.
* **Cybersecurity & CII**: National Critical Information Infrastructure Protection Centre (NCIIPC), CERT-In emergency directives, and I4C (Indian Cyber Crime Coordination Centre).
* **Money Laundering 3-Stage Cycle**: Placement, Layering, and Integration mapped against the Prevention of Money Laundering Act (PMLA), FIU-IND, and the FATF 2024 Mutual Evaluation Report.
* **Border Management**: Frontier-by-frontier analysis of the Indo-Pak LOC/IB (CIBMS), China LAC, Indo-Bangladesh zero-line, and Indo-Myanmar Free Movement Regime (FMR) transition.
* **Central Armed Police Forces (CAPFs)**: Mandates and theaters for BSF, CRPF, ITBP, SSB, CISF, Assam Rifles, and the National Investigation Agency (NIA).

### 9. 📰 Current Affairs ➔ Static Linker
* Daily & weekly news developments mapped with a visual **"Static Linker"** to GS-III syllabus themes, relevant constitutional articles, and potential Prelims/Mains question angles.

### 10. 🎯 Prelims MCQ Exam Simulator
* **Authentic UPSC & UPPSC Formatting**: Statement-based questions (Statement I & II), Pair-matching questions (*"Only one pair" / "Only two pairs"*), and factual assertions.
* **Exam Engine**: Selectable 5, 10, or 20-question tests with active countdown timer, interactive question palette, and authentic UPSC scoring (+2.00 correct, -0.66 negative marking).
* **Pedagogical Feedback**: Detailed explanations dissecting *"Why Correct"*, *"Why Wrong"*, *"Memory Trap"*, and *"Memory Trick"*.
* **Automatic Mistake Book**: All incorrectly answered or flagged questions automatically log to the user's local Mistake Book for spaced repetition.

### 11. ✍️ Mains Answer Writing Lab
* **10-Marker (150 words) & 15-Marker (250 words) Real Simulator**:
  * Live word counter with color-coded alerts (under-length, target zone, word-limit exceeded).
  * Authentic countdown stopwatch (7 minutes for 10M, 11 minutes for 15M).
* **Directive Demystifier**: Explanations for key exam directives (*Critically Examine, Elucidate, Discuss, Evaluate, Analyze, Assess*).
* **Model Answer Evaluator**:
  * Standard 3-part framework (Introduction, Multi-dimensional Body, Forward-looking Conclusion).
  * Recommended schematic diagrams and flowcharts to sketch.
  * Verified data points and committee recommendations to cite.
* **Export & Print**: Save essays directly as PDF or print-friendly format.

### 12. 📚 Data Bank, Reports & Committee Vault
* **Official Data Bank**: Instant search for high-yield statistics across agriculture, manufacturing, renewables, and defence.
* **Landmark Reports Hub**: Executive takeaways from Economic Survey, NITI Aayog SDG Index, IPCC AR6, and RBI Financial Stability Reports.
* **Key Committees**: Quotes and recommendations from Shanta Kumar Committee (FCI restructuring), Ashok Dalwai Committee (Doubling Farmers' Income), Shekatkar Committee (Defence expenditure), and B.N. Srikrishna Committee (Data protection).
* **Best Practice Case Studies**: Hiware Bazar (Water harvesting), Sikkim (100% Organic farming), and Indore (Solid waste management).

### 13. 🧠 3D Flashcard & Revision Engine
* **Interactive 3D Flip Flashcards**: Practice key definitions, articles, and figures with fluid CSS 3D flip cards.
* **Exam Mnemonics**: Memorable acronyms (e.g., `SAMADHAN`, `5-5-1-4-7 Panchamrit`, `U-G-I-B`, `P-L-I`).
* **Personal Mistake Book**: Dedicated filterable manager for questions answered incorrectly in Prelims practice.
* **Spaced Repetition Schedule**: 1-day, 3-day, 7-day, 14-day, and 30-day review intervals.

### 14. 🏛️ UPPSC PCS GS-III Dedicated Module
* **UP Agricultural Landscape**: Regional disparities across Western UP, Eastern UP, Central UP, and Bundelkhand.
* **UP Defence Industrial Corridor**: Analysis of all 6 nodes (Aligarh, Agra, Kanpur, Lucknow, Jhansi, Chitrakoot).
* **Megaprojects & Connectivity**: Purvanchal, Bundelkhand, and Ganga Expressways; Jewar International Airport (Noida); and multimodal logistics hubs.
* **Terai Eco-Zone & Wildlife**: Dudhwa National Park, Pilibhit Tiger Reserve, and human-wildlife conflict mitigation.
* **Indo-Nepal 551 km Open Border Security**: Challenges involving SSB deployment, illicit trafficking, and trans-border rivers.

### 15. 🔄 Update Centre & Backup Engine
* **Offline Local Storage**: All personal notes, bookmarks, exam attempts, and mistake book entries are saved locally in the browser.
* **Live JSON/CSV Importer**: Validate and import custom questions, notes, and indicators directly in the browser with live schema linting.
* **Data Backup & Restore**: One-click JSON export/import to transfer your study data across devices seamlessly.

## 🚀 Quick Start & Local Development

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18 or higher recommended)
* `npm` package manager

### 1. Clone or Open the Workspace
```bash
cd "C:\Users\ragha\.gemini\antigravity\scratch\gs3-master"
```

### 2. Install Dependencies
```bash
# On Windows PowerShell:
npm.cmd install

# On macOS / Linux:
npm install
```

### 3. Launch Development Server
```bash
# On Windows PowerShell:
npm.cmd run dev

# On macOS / Linux:
npm run dev
```
Open `http://localhost:5173` in your browser. The app will boot with instant live reload enabled.

### 4. Build for Production
```bash
# On Windows PowerShell:
npm.cmd run build

# On macOS / Linux:
npm run build
```
The compiled, optimized distribution is emitted into the `dist/` directory ready for deployment.

## 🌐 Deploying to GitHub Pages

### Method A: Automated Deployment via GitHub Actions (Recommended)

1. Initialize a Git repository and commit your code:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of GS-III Master educational portal"
   ```
2. Create a new repository on GitHub (e.g. `gs3-master`).
3. Link your remote and push:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/gs3-master.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings** ➔ **Pages**:
   * Under **Build and deployment** ➔ **Source**, select **GitHub Actions**.
5. The pre-configured workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) will automatically build and publish your site at `https://<YOUR-USERNAME>.github.io/gs3-master/`.

### Method B: Manual Deployment via `gh-pages` Branch
```bash
npm.cmd run build
npx gh-pages -d dist
```
